# statted

A-League player & team analytics — a **React + Vite** single-page app built on the
[SkillCorner](https://skillcorner.com) open broadcast-tracking data (2024/25 A-League).

> Staged inside the `opendata` repo for now. Destined for its own private repo
> **`mgmt-alt/statted`** — move the contents of this folder to the repo root there.

## Pages (one component per graph)

| Route | File | What it is |
|---|---|---|
| `/` | `src/components/Home.jsx` | Landing + season KPIs |
| `/leaderboard` | `src/components/Leaderboard.jsx` | The Statted Score — 8 silos, re-weightable by role or archetype |
| `/explorer` | `src/components/Explorer.jsx` | Per-player scatter; silo tabs narrow the axis menus |
| `/profile` | `src/components/Profile.jsx` | Player card — silo faces + per-metric drill-down, searchable picker |
| `/compare` | `src/components/Radar.jsx` | Two players/clubs across every silo |
| `/heatmaps` | `src/components/Heatmaps.jsx` | Action heat-maps (10-match sample) |

Shared logic lives in `src/lib/` — `constants.js` (silo weights, colours), `data.js` (loads
the JSON, builds composites + both percentile bases), `scoring.js` (overall, contributions,
team aggregation, metric access), plus `store.jsx` (filters context) and `tip.js` (tooltip).
Every graph carries its own **Players / Teams** toggle; position + min-matches filters are shared.

## Data

`src/data/season_players.json` and `src/data/sample_events.json` are generated by the pipeline
in the `opendata` repo (`src/visualization/`). To refresh, rebuild there and copy the two files
from `src/visualization/output/` into `src/data/`.

## Club logos (optional)

Drop licensed logo files in `src/logos/` named by club slug (e.g. `sydney-fc.png`,
`ws-wanderers.svg`); each is bundled and shown in place of the drawn shield crest. Clubs without
a file keep the crest. Official crests are trademarked, so sourcing/licensing is up to you.

## Develop

```bash
npm install
npm run dev       # local dev server
npm run build     # production build -> dist/
npm run preview   # serve the build
```

Uses `HashRouter` and `base: './'`, so the build works on any static host (GitHub Pages, etc.)
with no server config.
